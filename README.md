# うれタネ

**Prototype 003 / Ver.0.16**

小さなうれしいを、育てよう。

「こうしてもらえたらうれしい」「自分でこれができたらうれしい」をタネとして残し、日々水をあげながら育てる小さなWebアプリです。

## Ver.0.15 の変更

- 「今日のうれタネ」画面の余白を見直し、自分用タネカードをコンパクト化
- 「育ち具合」は各タネの成長を主役にし、月間表示は **水やり回数 / 開花数** の小さな統計へ変更
- 「育てたタネ 1/1」のような、個別進捗と意味が重なる全体進捗表示を削除
- タネ登録画面の **キャンセル / タネを保存** を下部固定し、スクロール中も操作可能に変更
- 芽・葉・つぼみの途中成長は短いコンパクト演出にし、開花だけフル画面演出を維持
- タネごとの成長アイコンは設定回数に対する割合で切り替え
- 相手向けタネは未送信と届けた履歴を分離し、共有時に送るタネを選択可能

## 主な機能

- うれタネの追加・編集・削除
- 「今日 / 近々 / いつでも」の優先度
- 「相手に届ける / 自分で育てる」の指定
- 合計1〜99回 / 何回でも の回数設定
- 同じタネへの水やりは1日1回まで
- タネ → 芽 → 葉 → つぼみ → 花 の成長表示
- 水やり履歴と月間の水やり / 開花記録
- 相手向けタネの選択共有・届けた履歴
- Web Crypto API（AES-GCM）を利用した共有データ暗号化
- localStorage 保存

## セキュリティ / プライバシー

- ログイン・外部DB・分析ツールなし
- 通常利用時の外部通信なし
- ユーザーデータはブラウザの `localStorage` に保存
- `innerHTML` は使用せず、ユーザー入力はテキストとして描画
- 共有リンクを知っている人は内容を復号できるため、秘密情報・重要な個人情報は登録しない前提

## Ver.0.15 の変更

### 呼び名
- 設定画面に「あなたの呼び名（任意）」を追加。
- 1回保存すると、このブラウザの localStorage に保持し、以後の共有で自動使用。
- 共有するたびの再入力は不要。
- 共有リンクには、設定している場合のみ呼び名を暗号化して含める。
- 受信側では「○○から届いた、うれしいこと」と表示。
- 届いたタネ一覧・育ち具合・水やり履歴でも「○○から」を表示。
- 呼び名未設定／旧共有リンクは、従来どおり名前なしで表示。
- 最大20文字。本名ではなくニックネーム利用を推奨。

### 互換性
- schemaVersion と共有フォーマット v1 は維持。
- `senderName` / `sourceName` は任意項目なので、既存の端末データ・旧共有リンクもそのまま利用可能。

### Playwright
- 呼び名が再読み込み後も保持されることを確認。
- 共有時に再入力不要で、自動的に受信側へ届くことをE2E確認。
- 一覧・今日・育ち具合・履歴に送り主が表示されることを確認。
- 異なる送り主のタネを「別のタネ」で切り替えると、送り主表示も切り替わることを確認。
- スクリーンショット 14: 呼び名付き・複数送信元の届いたタネ。
