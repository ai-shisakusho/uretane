# うれタネ

**Prototype 003 / Ver.0.8**

小さなうれしいを、育てよう。

「こうしてもらえたらうれしい」「自分でこれができたらうれしい」をタネとして残し、今日ひとつ育てる小さなWebアプリです。

## Ver.0.8 の変更

- 同じうれタネは **1日1回まで** 育てられるルールを追加
- タネごとに合計回数を設定可能
  - **回数を決める**：1〜99回（デフォルト1回）
  - **何回でも**：日を変えれば繰り返し育てられる
- その日の上限に達したタネは「今日のうれタネ」候補から除外
- 合計回数に達したタネは候補から除外し、「咲ききりました」と表示
- タネ一覧・共有確認に回数ルールを表示
- 完了ボタンを **「できた！花を咲かせる」** に変更し、押した結果を分かりやすくした

## 主な機能

- うれタネの追加・編集・削除
- 「今日 / 近々 / いつでも」の優先度
- 「相手に届ける / 自分で育てる」の指定
- 回数制限（合計1〜99回 / 何回でも）
- 同じタネは1日1回まで
- 今日のうれタネを自動表示
- 別のタネへの切り替え
- 完了時の開花演出
- 咲いた花の履歴・育ち具合
- 相手向けタネの暗号化共有・取り込み
- localStorage 保存
- 全データ初期化

## デザイン方針

- UI・導線は「うれタネ プロトタイプ」をベース
- 芽・花・配色・アイコン表現は画面デザイン案を参考
- 通常時は生成り〜緑、開花時のみオレンジ系を強調
- 初回は「芽＋コピー＋タネをまく」の1CTAに集中

## セキュリティ / プライバシー

- ログイン・外部DB・分析ツールなし
- 通常利用時の外部通信なし
- データはブラウザの `localStorage` に保存
- `innerHTML` は使用せず、ユーザー入力はテキストとして描画
- 共有データは Web Crypto API の AES-GCM で暗号化し URL フラグメントに格納
- 共有リンクを知っている人は内容を復号できるため、秘密情報・重要な個人情報は登録しない前提
- 共有データ件数・文字数・形式・回数設定を検証してから取り込む
