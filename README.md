# Prototype 003 - うれタネ

**小さなうれしいを、育てよう。**

「こうだったらうれしい」をタネとして残し、相手や自分が今日ひとつ選んで育てる小さなWebアプリです。パートナー向けに限定せず、自分用のタネだけでも使えます。

## Ver.0.5

### UI

- UI構成・導線は「うれタネ プロトタイプ」を基準に再設計
- 初回0件画面は「芽 / コンセプト / タネをまく」の1アクションに集中
- 登録後のホームは「今日のうれタネ」を主役に整理
- タネがあればホーム表示時に優先度から自動で1件選択
- 自分用のタネは補助カードとして小さく表示
- 下部ナビを「今日 / タネ一覧 / 育ち具合」の3つに整理
- 設定は右上へ移動
- 育ち具合と過去の記録を同じ画面に統合
- タネ一覧は色・左罫線で相手向け / 自分向けを判別しやすく調整

### Visual

- アイコン・色・植物表現は「うれタネ 画面デザイン案」を参考
- 正式採用した芽アイコンをfavicon / アプリアイコンへ反映
- 花アイコンを開花演出・育ち具合へ反映
- 通常時は緑〜生成り、開花時のみオレンジ〜花色を強く表示
- 絵文字依存を減らし、CSS形状とSVGアイコンを利用
- OGP画像とWeb App Manifestを追加

### 機能

- うれタネの追加・編集・削除
- 「今日 / 近々 / いつでも」
- 「相手に届ける / 自分で育てる」
- 相手向けタネの共有リンク作成
- 共有リンクからの取り込み・更新・削除同期
- 「育てた！」履歴
- 完了時の開花演出
- 今月咲いた花・育てた種類 / 全体の簡易表示
- 各タネの実行回数・最終実行日時の表示
- 全データ初期化
- localStorage保存

## セキュリティ / プライバシー

- 外部API・外部ライブラリ・アクセス解析なし
- 通常データはブラウザの localStorage のみに保存
- ユーザー入力は `textContent` で描画し、`innerHTML` は使用しない
- 共有データは Web Crypto API の AES-GCM で暗号化し、URL のフラグメント（`#`以降）に格納
- 共有データ取込時に形式・件数・文字数を検証
- CSPで外部通信を禁止

共有リンクには復号に必要な情報も含まれるため、**リンクを知っている人は内容を開けます**。パスワード、カード番号、住所などの秘密情報・重要な個人情報は登録しない前提です。
